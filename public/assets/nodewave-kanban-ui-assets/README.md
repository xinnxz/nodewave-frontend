# Kanban UI Asset Pack

Editable SVG assets reconstructed from the supplied Kanban reference.

- `logos/`: blue, white and dark geometric brand-mark placeholders
- `status-icons/`: TODO, IN PROGRESS, IN REVIEW, DONE
- `badges/`: status, priority and department pills
- `navigation/`: sidebar and common action icons
- `avatars/`: neutral initials-based avatar placeholders
- `components/`: sample Kanban column header assets

The supplied reference uses the Canvaso wordmark. The geometric mark here is a replaceable placeholder, not an official Canvaso or NodeWave logo. SVGs are editable and scalable.
